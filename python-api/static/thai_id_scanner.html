📋 วิธีใช้งาน

  1. ดาวน์โหลดไฟล์ thai_id_local_agent.py
  2. ติดตั้ง: pip install flask flask-cors pyscard
  3. เสียบเครื่องอ่านบัตร GLINK เข้ากับ USB
  4. รัน: python thai_id_local_agent.py
  5. ใส่บัตรประชาชนในเครื่องอ่าน
  6. กดปุ่ม "สแกนบัตรประชาชน"
