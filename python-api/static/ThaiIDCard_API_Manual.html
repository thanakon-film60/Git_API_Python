1. ภาพรวมระบบ

Thai ID Card Scanner API เป็นระบบที่ช่วยให้เว็บแอปพลิเคชันสามารถอ่านข้อมูลจากบัตรประชาชนไทย ผ่านเครื่องอ่านบัตรสมาร์ทการ์ด (Smart Card Reader) รุ่น GLINK หรือเครื่องอ่านที่รองรับ PC/SC

✨ ความสามารถของระบบ

  • อ่านเลขบัตรประชาชน 13 หลัก
  • อ่านชื่อ-นามสกุล (ภาษาไทยและอังกฤษ)
  • อ่านวันเดือนปีเกิด และเพศ
  • อ่านที่อยู่ตามบัตร
  • อ่านวันออกบัตรและวันหมดอายุ
  • ส่งข้อมูลไป Cloud Server อัตโนมัติ

2. สถาปัตยกรรมระบบ

ระบบประกอบด้วย 3 ส่วนหลัก:

ขั้นตอนการทำงาน:

1 ผู้ใช้ เปิดโปรแกรม ThaiIDAgent.exe บนเครื่องคอมพิวเตอร์
2 ใส่บัตร ประชาชนในเครื่องอ่าน GLINK แล้วกดปุ่ม "สแกน"
3 โปรแกรม อ่านข้อมูลจากบัตรและส่งไป Railway Server
4 เว็บไซต์ เรียก API เพื่อดึงข้อมูลบัตรมาแสดง

3. การติดตั้งโปรแกรม ThaiIDAgent.exe

3.1 ดาวน์โหลดโปรแกรม

ดาวน์โหลดโปรแกรม ThaiIDAgent.exe จาก API:

GET https://believable-ambition-production.up.railway.app/api/thaiid/download

3.2 ความต้องการของระบบ

รายการ ความต้องการ
ระบบปฏิบัติการ Windows 10 / Windows 11
เครื่องอ่านบัตร GLINK Smart Card Reader หรือเครื่องอ่านที่รองรับ PC/SC
อินเทอร์เน็ต จำเป็น (สำหรับส่งข้อมูลไป Server)

4. วิธีใช้งานโปรแกรม

1 เสียบเครื่องอ่านบัตร USB เข้ากับคอมพิวเตอร์
2 ใส่บัตรประชาชน ในเครื่องอ่าน (chip หันลงด้านล่าง)
3 เปิดโปรแกรม ThaiIDAgent.exe
4 ตรวจสอบสถานะ - โปรแกรมจะแสดง:
  • ✅ พร้อมใช้งาน - เมื่อเจอเครื่องอ่านบัตร
  • ⚠️ ไม่พบเครื่องอ่าน - กรุณาเสียบ USB
5 กดปุ่ม "สแกนบัตรและส่งไป Railway"
6 รอจนสำเร็จ - โปรแกรมจะแสดงข้อมูลที่อ่านได้และสถานะการส่ง
✅ เมื่อสแกนสำเร็จ
ข้อมูลจะถูกส่งไป Railway Server ทันที และเว็บไซต์สามารถดึงข้อมูลได้ผ่าน API

5. API Endpoints

Base URL:

https://believable-ambition-production.up.railway.app

5.1 ดาวน์โหลดโปรแกรม

GET /api/thaiid/download

ดาวน์โหลดไฟล์ ThaiIDAgent.exe

Response คำอธิบาย
200 OK ไฟล์ ThaiIDAgent.exe (binary)
404 Not Found ไม่พบไฟล์

5.2 รับข้อมูลบัตรประชาชน

POST /api/thaiid/receive

รับข้อมูลจากโปรแกรม ThaiIDAgent.exe (ใช้โดยโปรแกรมอัตโนมัติ)

Request Body:

{ "data": { ... ข้อมูลบัตร ... }, "timestamp": "2025-12-11T10:30:00", "source": "ThaiIDAgent" }

5.3 ดึงข้อมูลบัตรล่าสุด ⭐

GET /api/thaiid/latest

ดึงข้อมูลบัตรประชาชนล่าสุดที่สแกนเข้ามา (ใช้ endpoint นี้ในเว็บไซต์)

Response สำเร็จ (200):

{ "success": true, "data": { "data": { "cid": "1-3098-01337-16-3", "name": { "th": { "fullName": "นาย ธนากร โฮงทอง" }, "en": { "fullName": "Mr. THANAKON HONGTHONG" } }, "birthDate": "15/06/2541", "gender": "ชาย", "address": { "full": "123 หมู่ 4 ..." } } }, "receivedAt": "2025-12-11T10:30:01" }

6. ตัวอย่างการเรียกใช้ API

6.1 JavaScript / React / Next.js

// ดึงข้อมูลบัตรล่าสุด const fetchCardData = async () => { const response = await fetch( 'https://believable-ambition-production.up.railway.app/api/thaiid/latest' ); const result = await response.json(); if (result.success) { console.log('เลขบัตร:', result.data.data.cid); console.log('ชื่อ:', result.data.data.name.th.fullName); } }; // เรียกใช้ fetchCardData();

6.2 React Hook พร้อม Auto-Refresh

import { useState, useEffect } from 'react'; function useThaiIDCard(refreshInterval = 3000) { const [cardData, setCardData] = useState(null); useEffect(() => { const fetchData = async () => { const res = await fetch( 'https://believable-ambition-production.up.railway.app/api/thaiid/latest' ); const data = await res.json(); if (data.success) setCardData(data.data.data); }; fetchData(); const interval = setInterval(fetchData, refreshInterval); return () => clearInterval(interval); }, [refreshInterval]); return cardData; }

8. การแก้ไขปัญหา (Troubleshooting)

❌ โปรแกรมไม่เจอเครื่องอ่านบัตร

สาเหตุ: เครื่องอ่านไม่ได้เสียบ หรือ Driver ไม่ได้ติดตั้ง

วิธีแก้:
  • ตรวจสอบว่าเสียบ USB แล้ว
  • ลองถอดแล้วเสียบใหม่
  • ตรวจสอบใน Device Manager ว่ามี Smart Card Reader หรือไม่
  • ลองเปลี่ยน USB Port อื่น

❌ "Smart card is not responding to a reset"

สาเหตุ: บัตรไม่ได้ใส่ถูกต้อง หรือ chip สกปรก

วิธีแก้:
  • ใส่บัตรให้แน่น (chip ต้องหันลงด้านล่าง)
  • ทำความสะอาด chip บนบัตรด้วยผ้านุ่ม
  • ลองถอดบัตรออกแล้วใส่ใหม่
  • ลองบัตรประชาชนใบอื่น

❌ ส่งข้อมูลไป Railway ไม่สำเร็จ

สาเหตุ: ไม่มีอินเทอร์เน็ต หรือ Server มีปัญหา

วิธีแก้:
  • ตรวจสอบการเชื่อมต่ออินเทอร์เน็ต
  • ลองเปิดเว็บ https://believable-ambition-production.up.railway.app ดูว่าเข้าได้ไหม
  • รอสักครู่แล้วลองใหม่

❌ เว็บไซต์ดึงข้อมูลไม่ได้ (404 Not Found)

สาเหตุ: ยังไม่มีการสแกนบัตร

วิธีแก้:
  • ต้องสแกนบัตรจากโปรแกรม ThaiIDAgent.exe ก่อน
  • ตรวจสอบว่าสแกนสำเร็จ (มีข้อความ "ส่งข้อมูลสำเร็จ")
  • เปิด Auto-Refresh ในเว็บไซต์
